💻 Dominando as Linhas de Comando

No desenvolvimento Back-End, interagimos diretamente com o servidor por meio do terminal, executando scripts e enviando queries para o banco de dados.


Abaixo você encontra a referência completa dos principais comandos utilizados nas aulas: 

npm init -y
npm install express
SELECT * FROM usuarios;

🛠️ Comandos de Terminal & NPM

🚀 Iniciar Projeto

Cria o arquivo package.json padrão no projeto.

npm init -y

📦 Instalar Pacote

Instala dependências como o express ou dotenv.

npm install express

⚡ Executar Servidor

Inicia a aplicação rodando o arquivo principal do servidor.

node server.js

🔄 Modo Dev (Nodemon)

Reinicia o servidor automaticamente a cada alteração.

npx nodemon index.js

🗄️ Comandos SQL (Banco de Dados)

01

CREATE TABLE

Cria uma nova tabela no banco de dados.

CREATE TABLE alunos (
  id INT PRIMARY KEY,
  nome VARCHAR(100)
);

02

INSERT INTO

Insere novos registros na tabela.

INSERT INTO alunos
(id, nome)
VALUES (1, 'Maria');

03

SELECT

Busca e filtra dados cadastrados.

SELECT * FROM alunos
WHERE id = 1;

04

UPDATE

Atualiza informações existentes.

UPDATE alunos
SET nome = 'Ana'
WHERE id = 1;

05

DELETE

Remove um registro específico do banco.

DELETE FROM alunos
WHERE id = 1;

06

DROP TABLE

Exclui permanentemente uma tabela inteira.

DROP TABLE alunos;

🔌 Métodos e Rotas HTTP (Express)

🟢 GET – Leitura e Busca

Utilizado para buscar informações do servidor sem alterar nada.

app.get('/usuarios', (req, res) => {
    res.json({ mensagem: 'Lista de usuários' });
});

🟡 POST – Criação de Registros

Utilizado para enviar dados do cliente e criar algo no servidor.

app.post('/usuarios', (req, res) => {
    const novoUsuario = req.body;
    res.status(201).json(novoUsuario);
});

🔵 PUT – Atualização Total

Substitui um registro inteiro pelos novos dados enviados.

app.put('/usuarios/:id', (req, res) => {
    const { id } = req.params;
    res.send(`Usuário ${id} atualizado.`);
});

🔴 DELETE – Remoção

Exclui um determinado recurso identificado por parâmetro na URL.

app.delete('/usuarios/:id', (req, res) => {
    const { id } = req.params;
    res.send(`Usuário ${id} deletado.`);
});

🚀 Estrutura Completa de um Servidor Express

Abaixo está a sintaxe base necessária para rodar uma API funcional: 

const express = require('express');
const app = express();

app.use(express.json());

app.get('/', (req, res) => {
    res.send('Servidor Back-End online! ⚙️');
});

app.listen(3000, () => {
    console.log('Servidor rodando em http://localhost:3000');
});
